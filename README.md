# Stock-APP

US Stock portfolio dashboard + FastAPI analysis API.

- **Frontend:** Vite/React → Netlify (`frontend/`)
- **API:** FastAPI → Render Free (`main.py`, `backend/`)
- **Data:** Supabase holdings + local market snapshots

See [DEPLOY.md](./DEPLOY.md) for Netlify + Render setup.

Local secrets live in `.env` (not committed). Copy `.env.example`.
